# 教务管理系统 —— 接口测试用例

测试对象：后端 REST 接口（Node.js + Express + MySQL）
测试方式：自动化脚本 `test/api.test.mjs`（Node 原生 fetch + assert）
测试账号：`admin` / `t001` / `s001`，密码均为 `123456`（客户端 cyrb53 加密后提交）
接口约定：HTTP 统一 200，业务状态在响应体 `code` 字段（200 成功 / 401 未登录 / 403 无权限 / 500 失败）

## 一、登录与鉴权

| 编号 | 测试场景 | 前置条件 | 测试步骤 | 预期结果 |
| --- | --- | --- | --- | --- |
| TC-01 | 管理员正确登录 | 无 | POST /login，admin / 123456 / admin | code=200，返回 token 与用户信息，role=admin |
| TC-02 | 教师正确登录 | 无 | POST /login，t001 / 123456 / teacher | code=200，返回 token |
| TC-03 | 学生正确登录 | 无 | POST /login，s001 / 123456 / student | code=200，返回 token |
| TC-04 | 密码错误 | 无 | POST /login，admin / 错误密码 / admin | code≠200，提示含“密码” |
| TC-05 | 身份与账号不匹配 | 无 | POST /login，admin 账号选“学生”身份 | code≠200 |
| TC-06 | 账号不存在 | 无 | POST /login，nobody-999 / admin | code≠200 |
| TC-07 | 未携带 token | 无 | GET /user/info，不带 Authorization | code=401 |
| TC-08 | 非法 token | 无 | GET /user/info，Authorization 为伪造串 | code=401 |
