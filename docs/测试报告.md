## 四、重点验证项

- **身份鉴权**：无 token、非法 token 均被拦截（code=401），token 校验有效。
- **权限隔离（重点）**：学生、教师访问管理员专属接口均返回 403；学生访问教师接口返回 403；权限控制在服务端生效，不依赖前端隐藏菜单。
- **敏感字段**：用户信息接口返回数据不含 `password` 字段。
